THE ENGINE IN 30 SECONDS

Three ideas. No magic.

01 · Write path

Durable before ACK

client → WAL fsync → VLog(NVMe) → ack

Group-commit WAL batches concurrent writes into one fsync. Values land in an append-only log — written once, never rewritten.

02 · Read path

One NVMe read, worst case

key → DRAM index → cache hit 0.3ms | miss → io_uring → 4.9ms

A 24-byte pointer per key in DRAM. Cache miss costs exactly one O_DIRECT read — no page-cache roulette, no compaction in the way.

03 · Scale

1024 shards, zero hot locks

shard = hash(key) → own queue → own disk lane

Each shard owns its I/O submission queue. Eight NVMe devices write in parallel like a storage controller, not a database.
